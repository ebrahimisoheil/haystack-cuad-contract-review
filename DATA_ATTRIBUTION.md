# Data attribution

This repository does not distribute downloaded CUAD contracts, generated
subsets, scanned derivatives, or review outputs. Those paths are excluded from
source control and are created locally by the documented ingestion commands.

The optional ingestion workflow uses the Contract Understanding Atticus
Dataset (CUAD), created by the Atticus Project:

> Dan Hendrycks, Collin Burns, Anya Chen, and Spencer Ball. “CUAD: An
> Expert-Annotated NLP Dataset for Legal Contract Review.” NeurIPS, 2021.

Official project: https://github.com/TheAtticusProject/cuad

Users who download or redistribute CUAD data are responsible for reviewing the
current dataset terms, preserving attribution and provenance, and ensuring they
have the right to process any contracts they supply. The MIT license in this
repository applies only to this repository's original source code and synthetic
test fixtures; it does not relicense third-party contracts or datasets.
