# Security policy

## Supported version

The latest commit on the default branch is supported while this project is in
its pre-1.0 demonstration phase.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature instead of opening
a public issue. Include reproduction steps, affected files or versions, and the
potential impact. Do not include real contracts, credentials, or personal data.

Provider credentials belong only in a local `.env` or secret manager. This
repository intentionally excludes `.env`, downloaded datasets, generated
contracts, and analytics output from source control.
